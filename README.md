# תקציב הבית 🏠

אפליקציה לניהול כלכלת משק הבית: הכנסות, הוצאות קבועות ושוטפות, חלוקה בין חשבון פרטי של **יולי**, חשבון פרטי של **נעמה** וחשבון **משותף**, וסיכום כולל של כל מה שנכנס ויוצא.

האפליקציה עובדת ישירות בדפדפן, ללא שרת וללא הרשמה. הנתונים נשמרים מקומית במכשיר (`localStorage`), וניתן לייצא ולייבא אותם כקובץ גיבוי.

## איך פותחים

**הדרך הקצרה – קישור בדפדפן.** האפליקציה מפורסמת כעמוד באתר claude.ai:
<https://claude.ai/artifact/5XxRpRkiA1MW6E1Z5Wwe8i>. פותחים בטלפון או במחשב, אפשר
להוסיף למסך הבית. בגרסה הזו הנתונים נשמרים באחסון המשותף של האפליקציה, כך שכל מי
שפותח את הקישור רואה את אותם נתונים – בכל מכשיר. כשהסנכרון פעיל מופיע הסימון
"מסונכרן" בראש העמוד.

**הרצה מקומית** – למי שרוצה להריץ מהקוד (דורש Node.js 20 ומעלה):

## הפעלה

```bash
npm install
npm run dev        # סביבת פיתוח (http://localhost:5290)
npm run build      # בנייה לפרודקשן לתיקיית dist
npm run preview    # תצוגה מקדימה של הבנייה (http://localhost:4290)
npm run build:artifact  # בנייה + הכנת עמוד יחיד לפרסום כ-Artifact
```

הפורטים נקבעים ב-`vite.config.ts` (5290 לפיתוח, 4290 לתצוגה מקדימה) – הרחק
מברירות המחדל של Vite שנוטות להיות תפוסות. אם גם הפורט הזה תפוס, Vite עובר לבד
לפורט הפנוי הבא ומדפיס את הכתובת. לפורט חד-פעמי אחר:

```bash
npm run dev -- --port 5400
```

הבנייה יוצרת קבצים סטטיים בלבד (`base: './'`), כך שאפשר להעלות את תוכן `dist/` לכל אחסון סטטי – GitHub Pages, Netlify, או אפילו תיקייה משותפת.

## איך מסומן מאיפה יצא הכסף

לכל תנועה יש **חשבון מקור**: החשבון הפרטי של יולי, החשבון הפרטי של נעמה, או החשבון המשותף. כל חשבון משויך לבעלים, ולבעלים יש צבע קבוע שמלווה אותו בכל המסכים – בטבלאות, בגרפים ובסיכומים. כך אפשר לראות בכל רגע כמה יצא מכל כיס.

הכנסות מסומנות פעמיים: לאיזה חשבון הן נכנסו, ו**של מי** הן (יולי / נעמה / משותף, למשל קצבת ילדים). זה מה שמאפשר את החלוקה היחסית בהתחשבנות.

## איך עובדת ההתחשבנות

המטרה: לענות על השאלה "מי שילם יותר מחלקו החודש".

1. **מה כל אחד נשא בפועל** = ההוצאות ששולמו מהחשבון הפרטי שלו + חלקו בהוצאות שיצאו מהחשבון המשותף. החלק בחשבון המשותף נקבע לפי חלקו במימון החשבון (העברות קבועות + הכנסות שנכנסו ישירות למשותף), כך שאין ספירה כפולה.
2. **החלק ההוגן** נקבע לפי שיטת החלוקה שנבחרה בהגדרות:
   * חלוקה שווה (50/50),
   * חלוקה יחסית להכנסות (ברירת המחדל),
   * חלוקה מותאמת באחוזים.
3. **המאזן** = מה שנשא פחות החלק ההוגן. מאזן חיובי = שילם מעבר לחלקו, והאפליקציה מציעה בדיוק כמה כסף להעביר ולמי.

## תדירויות נתמכות

חודשי, דו-חודשי (ארנונה, חשמל, מים), רבעוני, חצי שנתי, שנתי (טסט לרכב, ביטוחים) ושבועי. חיובים שאינם חודשיים מוצגים גם כ"ממוצע לחודש", כדי שתמונת ההוצאות החודשית תהיה אמיתית.

## הנתונים שלכם

* בגרסה המפורסמת הנתונים נשמרים באחסון המשותף של האפליקציה ומסונכרנים בין כל מי
  שפותח את הקישור. בהרצה מקומית הכול נשמר בדפדפן של המכשיר בלבד.
* במסך ההגדרות אפשר **לייצא גיבוי JSON** ולטעון אותו במכשיר אחר (כך גם משתפים את אותו מצב בין שני בני הזוג).
* כפתור **"התחלה מאפס"** מוחק את נתוני הדוגמה ומאפשר להזין נתונים אמיתיים. כפתור **"איפוס לנתוני דוגמה"** מחזיר את המצב ההתחלתי.
* האפליקציה מגיעה עם נתוני דוגמה מלאים (שכר דירה, גן, מנויים, משכורות, העברות לחשבון המשותף ועוד) כדי שאפשר יהיה להתרשם מכל המסכים מיד – מומלץ להחליף אותם בנתונים שלכם.

## צבעים

לכל בן בית יש צבע זהות שמלווה אותו בכל המסכים – בטבלאות, בגרפים ובסיכומים. הצבעים
ניתנים לשינוי במסך ההגדרות, ולכל קטגוריה אפשר לקבוע צבע משלה בעת ההוספה או העריכה.

לוח הצבעים המוצע (וכן צבעי ברירת המחדל) נבחר מפלטה שעברה אימות ניגודיות והבחנה
בעיוורון צבעים בשני מצבי התצוגה. צבעי ברירת המחדל מתאימים את עצמם למצב בהיר וכהה;
צבע שנבחר ידנית נשאר זהה בשניהם. בנוסף אפשר לבחור צבע חופשי לגמרי.
